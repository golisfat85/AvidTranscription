To use Avid Transcription inside Avid Media Composer:

  1. Open AvidTranscription.app from your Applications folder to start the server.
  2. Launch Avid Media Composer.
  3. Go to Windows → Panels → AvidTranscription.
  4. Select a clip in your bin, click From Bin, then Transcribe.

If FFmpeg is not yet installed, run:
brew install ffmpeg
