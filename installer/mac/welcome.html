Avid Transcription Plugin

This installer will set up:

  • The Avid Transcription Python package
  • The Avid Media Composer panel (docked inside MC)
  • AvidTranscription.app in your Applications folder

Requirements:
• Python 3.9+ (from python.org)
• FFmpeg (install after via brew install ffmpeg)
• Avid Media Composer 2018.x or later
